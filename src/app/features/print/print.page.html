Impressão

Monte uma folha A4 para impressão. Traga artes do lote pelo botão "Adicionar à impressão" (em cada arte pronta) e/ou envie imagens avulsas aqui. Ajuste a quantidade de cada arte; o sistema organiza os bottons (tamanhos mistos) de forma otimizada. Depois é só imprimir — o diálogo do navegador também salva em PDF.

Adicionar imagem avulsa

Envie uma imagem (PNG ou JPEG), escolha o tamanho e a quantidade. Ela entra na mesma folha, com círculo e linha de corte como as artes do lote.
