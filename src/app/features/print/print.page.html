Impressão

Monte uma folha A4 para impressão. Traga artes do lote pelo botão "Adicionar à impressão" (em cada arte pronta) e/ou envie imagens avulsas aqui. Ajuste a quantidade de cada arte; o sistema organiza os bottons (tamanhos mistos) de forma otimizada. Depois clique em Imprimir para ver a prévia, escolher a impressora e imprimir.

Adicionar imagem avulsa

Envie uma imagem (PNG ou JPEG), escolha o tamanho e a quantidade. Ela entra na mesma folha, com círculo e linha de corte como as artes do lote.
